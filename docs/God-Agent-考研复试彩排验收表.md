## 1. 验收规则

### 1.1 每次彩排必须保存

- 日期、地点/设备、演讲者、计时者；
- 开始/结束时间和净用时；
- 使用的源码提交或工作树标识、演示材料版本；
- 网络状态、Provider 状态、是否有 Key；
- 录屏/录音/照片或观察记录的实际路径；
- 问题、严重度、负责人、修订内容和复验结果；
- 数字口径检查结果，不允许沿用旧测试数量；
- 参与者签名或可核验确认。

### 1.2 状态定义

| 状态 | 定义 |
|---|---|
| `NotRun` | 尚未实际执行；默认状态 |
| `Run-Failed` | 已执行，但超时、关键内容遗漏、演示中断或事实口径错误 |
| `Run-Conditional` | 已执行，存在非关键问题，完成指定复验后才可通过 |
| `Passed` | 已执行且满足本轮全部通过条件，有可核验证据 |

### 1.3 通用通过条件

- 主讲净用时控制在 `2:45–3:10`；
- 30 秒内说明问题，90 秒内说明机制与证据边界；
- 清楚展示 WAL、Lease/Fencing、Return Receipt、`outcome_unknown`；
- 主动说明 GATE-40 为 candidate 40、local pilot 25 passed / 0 failed / 15 blocked、formal Verified 0、`complete=false`；
- 主动说明 Provider `liveCalls=0`，不暗示真实 Provider 已验证；
- 主动说明 Release 为 11/12、`BLOCKED`，production `blocked` 和 3 high；
- 测试数使用“最近一次已知值 + 动态口径”，不把测试数换算为可靠性百分比；
- 至少正确回答 5 个随机追问，其中必须包含创新、外部基线、exactly-once、统计和 AI 边界；
- 断网、无 Key、依赖异常任一发生时，能在 20 秒内切到冻结 Artifact/截图/视频并明确现场状态；
- 不展示 Key、Token、私有 URL、账户信息或不可撤销真实操作。
